# SigmaOS-distro

> **SigmaOS Distribution Engine** — Base configuration, image composition, branding, and system profiles.

Part of the [SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS) ecosystem.  
Combines the control of Arch Linux, the aesthetic polish of Omarchy, and the onboarding simplicity of Linux Mint.

## Quickstart

```bash
cargo check --release
cargo test
```

Full documentation, architecture guides, and roadmaps are maintained on the [SigmaOS GitHub Wiki](https://github.com/AaryanSinghChauhan09/SigmaOS/wiki).
